# Skills

Shared reusable skill catalog for local agents.

This repository contains:

- domain catalogs with `DESCRIPTION.md` indexes
- individual skills in folders with `SKILL.md`
- supporting scripts, references, templates, and assets

Shared runtime for skill scripts is not stored in this repository.
It lives one level above, in the top-level `/runtime/` folder.

Project-specific skills live in the separate `project-skills/` repository.
